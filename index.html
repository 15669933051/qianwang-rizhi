📖 使用说明

  • 所有数据只保存在本机浏览器（localStorage），不上传服务器；换手机请用「全部日志备份」导出 json 再导入。
  • 导出 Word 为纯前端现场生成（不依赖任何网络或第三方库），表格严格按施工日志模板：信息表 + 生产记录 + 技术质量安全 + 材料进场 + 现场照片（3 张一行）+ 签字栏。
  • 照片在拍照时已压缩（长边 1000px），导出时直接写入文档，不再二次解码，手机内存占用小。
  • 导出耗时：生成过程为纯本地计算，电脑实测 0 张 0.4 毫秒、6 张 4.5 毫秒、12 张 8 毫秒；手机约为其 10～20 倍（0.1～0.3 秒），主要时间花在保存文件上。
  • 如需纸质打印或 PDF，点日志卡片上的「打印/存PDF」，A4 排版与 Word 一致。
